A self-contained Three.js WebGL scene of rising determination particles, a glowing ascending spine, and cinematic lighting. Hyper-realistic material response (metalness, roughness, emissive, tone mapping) with animated particle streams that refuse to fall.

No build step. Open `index.html` or deploy statically.

## Deploy

GitHub Pages, Vercel, Netlify, or any static host. Point the root to this directory.
